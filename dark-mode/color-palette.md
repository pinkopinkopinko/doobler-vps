# Dark Mode Concept

Черновик темной темы для Doobler. Идея: приложение не превращаем в черный экран с белым текстом. Фон делаем глубоким темно-сине-серым, а все читаемые блоки оставляем на светлых/дымчатых карточках, поэтому основной текст остается черным.

## Главное правило

- Белый текст не используем для основного интерфейса.
- Основной текст: `#101214`.
- Вторичный текст: `#4e5d6c`.
- Слабый текст/подписи: `#6f7883`.
- На темном фоне текст напрямую почти не кладем. Если нужно что-то написать, сначала даем светлую подложку.

## Палитра

### Page

- `--dm-page`: `#101820` — основной фон приложения.
- `--dm-page-soft`: `#16222c` — мягкий градиентный слой сверху.
- `--dm-page-glow-blue`: `rgba(51, 135, 209, 0.22)` — холодное свечение.
- `--dm-page-glow-green`: `rgba(92, 172, 132, 0.18)` — спокойное зеленое свечение.

### Surfaces

- `--dm-card`: `#f4f7f9` — основные карточки, чтобы текст был черным.
- `--dm-card-raised`: `#ffffff` — важные карточки и формы.
- `--dm-card-muted`: `#e9eef3` — вторичные панели.
- `--dm-chip`: `#eef3f7` — чипы, бейджи, disabled-кнопки.
- `--dm-border`: `rgba(16, 18, 20, 0.12)` — контур на светлых карточках.
- `--dm-dark-border`: `rgba(244, 247, 249, 0.12)` — контур поверх темного фона.

### Text

- `--dm-text`: `#101214` — весь основной текст.
- `--dm-text-muted`: `#4e5d6c` — описания.
- `--dm-text-soft`: `#6f7883` — подписи и мета.
- `--dm-text-disabled`: `#9aa4ae` — неактивные состояния.

### Actions

- `--dm-primary`: `#3387d1` — основной синий, как сейчас.
- `--dm-primary-hover`: `#2877bd`.
- `--dm-primary-text`: `#101214` — по твоему требованию не белый.
- `--dm-primary-surface`: `#d9ebfb` — если на синей кнопке черный текст недостаточно читается, используем светло-синюю кнопку.

### Status

- `--dm-success-bg`: `#dff2e8`.
- `--dm-success-text`: `#174c33`.
- `--dm-warning-bg`: `#fff1d5`.
- `--dm-warning-text`: `#6d4a16`.
- `--dm-danger-bg`: `#ffe3df`.
- `--dm-danger-text`: `#7a2922`.

## Как это должно выглядеть

- Общий экран: темный фон `#101820` с мягкими пятнами синего/зеленого свечения.
- Нижняя навигация: светлая плавающая панель `#f4f7f9`, текст и иконки черные/серые.
- Карточки смен, профиля, откликов: светлые, почти как сейчас, но с более выраженной тенью на темном фоне.
- Primary-кнопки: лучше светло-синие `#d9ebfb` с черным текстом, а не насыщенно-синие с белым.
- Disabled-кнопки: `#e9eef3` с `#9aa4ae`.
- Зеленые success-состояния: мягкая зеленая заливка, без кислотности.

## Черновые CSS Tokens

```css
:root[data-theme="dark"] {
  --app-bg: #101820;
  --app-bg-soft: #16222c;
  --app-card: #f4f7f9;
  --app-card-raised: #ffffff;
  --app-card-muted: #e9eef3;
  --app-border: rgba(16, 18, 20, 0.12);

  --app-text: #101214;
  --app-text-muted: #4e5d6c;
  --app-text-soft: #6f7883;
  --app-text-disabled: #9aa4ae;

  --app-primary: #d9ebfb;
  --app-primary-strong: #3387d1;
  --app-primary-text: #101214;

  --app-success-bg: #dff2e8;
  --app-success-text: #174c33;
  --app-warning-bg: #fff1d5;
  --app-warning-text: #6d4a16;
  --app-danger-bg: #ffe3df;
  --app-danger-text: #7a2922;
}
```

## Что делать при внедрении

1. Сначала вынести текущие повторяющиеся цвета в CSS variables.
2. Затем добавить `data-theme="dark"` на корневой layout/AppShell.
3. Перевести страницы по очереди: shell, bottom nav, cards, forms, chat.
4. После каждой страницы проверять, что нет `text-white` и белого текста на кнопках.
5. Белые карточки можно оставить, но фон вокруг них сделать темным, чтобы тема ощущалась темной без потери читаемости.
