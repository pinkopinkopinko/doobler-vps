# Doobler Tech Support Bot

Telegram-бот поддержки Дублера с тикетами.

## Что делает

- создает тикет при первом сообщении пользователя;
- добавляет новые сообщения пользователя в открытый тикет;
- хранит тикеты и историю в Postgres;
- отправляет администратору карточку тикета, профиль Дублера и вложения;
- позволяет отвечать клиенту реплаем на карточку тикета или командой;
- позволяет закрывать и повторно открывать тикеты.

## Команды пользователя

- `/start` или `/help` - приветствие и подсказка;
- `/ticket` - начать создание заявки или показать открытую заявку;
- `/close` - закрыть свой открытый тикет.

Пользователь должен сначала написать `/ticket`, затем текст обращения.
Подтверждение "Спасибо за обращение" отправляется только при создании новой заявки
и не повторяется для следующих сообщений до `/close`.

## Команды администратора

- `/tickets` - список открытых тикетов;
- `/ticket 123` - детали тикета и последние сообщения;
- `/reply 123 текст` - ответить клиенту;
- `/close 123` - закрыть тикет;
- `/open 123` - открыть тикет снова.

Администратор также может ответить реплаем на карточку тикета или пересланное вложение.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. Вставьте токен бота в `TELEGRAM_BOT_TOKEN`.
3. Укажите `DUBLER_DATABASE_URL`.
4. Запустите:

```bash
npm start
```

Бот работает через long polling, поэтому webhook для него не нужен.
